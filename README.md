# tasks-app

المنظومة المدرسية الشاملة — مدرسة عثمان بن عفان الابتدائية

نظام إداري متكامل يعمل من المتصفح (PWA) بدون خادم خلفي مخصص، مع مزامنة سحابية اختيارية عبر Supabase. يشمل:

- تسجيل دخول بأدوار وصلاحيات (مسؤول النظام، مدير المدرسة، الوكلاء الثلاثة، المرشد الطلابي، خدمة المستفيد، راصد الحضور، منسوب)
- لوحة معلومات قابلة للتخصيص بالمؤشرات والرسوم البيانية
- خدمة المستفيد (الزوار، تأخر الطلاب، الاستئذان)
- الحضور والغياب اليومي وتقاريره
- إدارة الطلاب (يدوياً أو استيراد CSV)
- الموظفون والمهام والإنجازات
- غياب المعلمين وسد الانتظار وتقرير الفاقد التعليمي
- المرشد الطلابي (حالات فردية، خطابات، خطة تعديل السلوك)
- السلوك والمواظبة وفق لائحة السلوك والمواظبة (الإصدار الخامس 1447هـ)
- أقسام الوكلاء الثلاثة (تعليمية، طلابية، مدرسية)
- إدارة المستخدمين والصلاحيات، سجل الحركات، الإعدادات والنسخ الاحتياطي

## البنية

- `index.html` — هيكل الصفحة
- `style.css` — التنسيق
- `app.js` — منطق التطبيق كاملاً (تخزين محلي + مزامنة سحابية)
- `manifest.json`, `service-worker.js` — دعم PWA
- `n8n/` — ورش عمل جاهزة للأتمتة (إشعارات أولياء الأمور، تقارير يومية/أسبوعية، نسخ احتياطي، تذكيرات داخلية) — راجع `n8n/README.md`
